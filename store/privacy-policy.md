# Privacy Policy — ChromeCuts

**Last updated:** 2026-08-01

ChromeCuts (“the extension”) is a Chrome extension that provides custom keyboard shortcuts for tab navigation and tab management.

## Data collection

ChromeCuts does **not** collect, sell, share, or transmit personal or browsing data. It does not include analytics, advertising SDKs, crash reporters, or accounts.

## Permissions

The extension uses only the following Chrome permissions, and only on your device:

| Permission | Purpose |
|------------|---------|
| `tabs` | Switch, move, pin, duplicate, close, reload, mute, or discard tabs in response to shortcuts you configure |
| `sessions` | Restore the most recently closed tab when you use that shortcut |

Tab and session information is used **only in memory** to perform the action you requested. It is not written to extension storage for tracking, not logged to a server, and not sent off your device.

## Remote code

All extension code is included in the installed package. ChromeCuts does not load or execute remote code.

## Changes

If this policy changes in a material way, the “Last updated” date will be revised and users will be notified as required by Chrome Web Store policy.
