ChromeCuts

Custom keyboard shortcuts for Chrome, starting with tab navigation.

How to remap keys

  1. Click Open Chrome shortcut settings (or go to chrome://extensions/shortcuts).
  2. Find ChromeCuts in the list.
  3. Click the pencil next to any command and press the keys you want.
  4. Return here and reload this page to see the updated bindings.

Chrome requires remapping through its own shortcuts page — extensions cannot capture arbitrary global keys without that step. Defaults below are suggestions; if a combo conflicts with another extension or OS shortcut, set your own.

Default suggestions

These are the keys suggested on install (Alt-based so they rarely fight Chrome’s Cmd/Ctrl defaults). Remap freely.

⌘⇧J Previous tab (was ⌘⇧[)
⌘⇧K Next tab (was ⌘⇧])
⌥⇧K Move tab left
⌥⇧J Move tab right

Same modifiers as Chrome’s tab switchers; only the key changes (J/K instead of [/]). On Windows/Linux that’s Ctrl+Shift+J / Ctrl+Shift+K. Chrome only auto-binds up to four suggested shortcuts — assign the rest at chrome://extensions/shortcuts.
